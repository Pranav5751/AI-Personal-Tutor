# AI Personal Tutor

## About This Project

AI Personal Tutor is a collection of specialized
AI learning projects designed to help students
understand academic subjects from the basics.

The goal is to focus on conceptual understanding
rather than memorization.

## Projects

### 1. Mathematics Tutor
A personalized tutor for understanding mathematical
concepts, prerequisites, formulas, and problem-solving.

### 2. Programming Tutor
A coding tutor specializing in C, Python, NumPy,
and Pandas, with detailed explanations of code
and programming logic.

### 3. Electrical and Electronics Tutor
A tutor for electrical and electronics engineering,
covering circuit analysis, AC circuits, op-amps,
and semiconductor fundamentals.

## Teaching Philosophy

- Start from absolute basics.
- Explain prerequisites before advanced topics.
- Explain why each formula and step is used.
- Never skip important intermediate steps.
- Focus on understanding instead of memorization.

## Purpose

To make learning easier, clearer, and more effective
through personalized AI-assisted teaching.
